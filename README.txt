TAP CIRCLES - simple Android game
=================================
1. Install Android Studio (Koala or newer recommended).
2. File > Open > select this TapGame folder.
3. Wait for "Gradle sync" to finish (first time downloads Gradle, needs internet).
4. Pick an emulator or plug in your phone (USB debugging on) and press the green Run button.

Edit the game: app/src/main/java/com/example/tapgame/GameView.kt
(see the CONFIG section at the top to tweak speed, lives, colors, size)
